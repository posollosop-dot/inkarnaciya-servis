# Инкарнация Сервис

## Зачем

Страница-визитка для бизнеса восстановления данных и смежных компьютерных услуг. Нужна,
чтобы была нормальная ссылка (не только объявления на Авито) и чтобы со временем страница
начала показываться в поиске Google/Яндекс по релевантным запросам.

## Ход работы и решения

- 2026-11-16 — проект создан. Решено: без фреймворков и сборщиков (чистый HTML/CSS), публикация
  через GitHub Pages (бесплатно, у пользователя уже есть аккаунт GitHub). Из услуг на Авито на
  сайт выносим только удалённые: восстановление данных, установка/переустановка Windows,
  удаление вирусов, снятие пароля WinRAR — без замены матрицы и термопасты (требуют выезда).

## Публикация на GitHub Pages (сделать самому)

1. Зайди на github.com → New repository → назови, например, `inkarnaciya-servis` → Create
   repository (без README, он уже есть здесь).
2. В терминале этого проекта:
   ```bash
   cd ~/Project/Inkarnaciya-Servis
   git remote add origin https://github.com/<твой-логин>/inkarnaciya-servis.git
   git branch -M main
   git push -u origin main
   ```
   Git попросит логин и токен/пароль GitHub — это твои данные, их вводишь ты сам.
3. На GitHub: Settings → Pages → Source: ветка `main`, папка `/ (root)` → Save.
4. Через пару минут сайт будет доступен по адресу вида
   `https://<твой-логин>.github.io/inkarnaciya-servis/`.
