## Стек и ограничения

Чистый HTML/CSS, без фреймворков и сборщиков — в этом рабочем месте нет npm/pip (см. память
проекта avito-bot `env-no-package-manager`). Публикация — GitHub Pages на аккаунте пользователя;
в месте нет `gh` CLI, поэтому первый push и включение Pages в настройках репозитория пользователь
делает сам (пошаговая инструкция — в README.md).

## Правила работы

- Работа — сессиями (`start-session` → `end-session`): журналы `sistem/JOURNAL-WORK.md` и
  `JOURNAL-TIME.md` пишутся при закрытии.
- Задачи — только командой `zadachi` (`zadachi список --проект Inkarnaciya-Servis`),
  `sistem/TASKS.md` руками не править.
- Секреты — только в `.env`, никогда в код и git (для этого сайта секретов, скорее всего, не
  будет — сайт статический, без ключей и форм с бэкендом).
- На сайт не выносить услуги «замена матрицы» и «термопаста» — только удалённые услуги.
